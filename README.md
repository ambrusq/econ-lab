# econ-lab
An open-ended project exploring how economic and social phenomena can emerge from simple computational models.

Starting with Monte Carlo and dynamic simulations, progressing toward agent-based models, learning agents, and eventually AI-driven economic simulations.

The objective is to understand how assumptions about individual behavior, institutions, and interactions translate into aggregate economic outcomes.
